

# AI Usage Disclosure

## AI Tools Used

- Claude

## How AI Was Used
AI tools were used to:
- Help plan and organize the repository structure.
- Understand previous AI-generated pushes, commits, and changes in the repository.
- Explain project concepts, code structure, and implementation details.
- Review code written by the team, identify potential errors, and suggest improvements.
- Assist with debugging, testing ideas, documentation, and clarification of requirements.

## Team Implementation and Responsibility
The main implementation of the project, including its core functionality and protocol logic, was carried out by the team. AI tools were used primarily for planning, understanding, and reviewing the code rather than generating the complete core implementation.

All AI-generated suggestions were reviewed and validated by the team. We are responsible for the submitted code and its correctness, and all team members are expected to understand and explain the implementation during evaluation.
